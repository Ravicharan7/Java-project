Storage          File         Size (bytes)   Accounts   Transactions
Serialization    bank.dat              683          2              3
Text file        bank.txt              215          2              3

Advantages of serialization over text file storage:
1. One call (writeObject / readObject) saves and restores the whole HashMap,
   every Account and the ArrayList of Transactions inside it.
   The text file needs our own format, writing code and parsing code.
2. Data types are kept (int, double, Date). In a text file everything is text
   and must be converted back, and bad text can cause errors.
3. The link between an account and its transactions is restored automatically.
4. Less code, so fewer mistakes (a name with the separator | would break the text file).
Limits of serialization:
1. The file is not readable by humans and only Java programs can read it.
2. If the classes are changed, old files may not load.
3. Here the serialized file is 468 bytes bigger, because it also stores class information.
